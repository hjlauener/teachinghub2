Themen × Journey

Wo die Kernthemen im Lehrzyklus vorkommen. Jeder Kreis zählt die bestehenden Seiten im Teaching Hub, die zu einem Thema und einer Phase gehören. Ein Klick auf ein Thema, eine Phase oder einen Kreis zeigt die Seiten darunter.

Kreisgrösse = Anzahl Seiten keine Seite Gesamt unter 5 = zu dünn für eine eigene Landingpage

Prototyp, Stand 19.11.2026. «Entwurf» = Zuordnung aus den Landingpages KI und Digitale Lehre. «Vorläufig» = erste Zuordnung bestehender Journey-Seiten, noch nicht geprüft.
